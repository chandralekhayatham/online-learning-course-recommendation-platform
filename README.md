# 🎓 Online Learning & Course Recommendation Platform

## 📌 Project Overview

The Online Learning & Course Recommendation Platform is a web-based application that helps students discover, enroll in, and manage online courses. The platform provides personalized learning recommendations and an interactive dashboard for learners.

This project was developed using React.js and follows a component-based architecture to create a responsive and user-friendly learning experience.

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Navigate to Project Folder

```bash
cd online-learning-course-recommendation-platform/client
```

### Install Dependencies

```bash
npm install
```

### Run Application

```bash
npm start
```

Application runs at:

```text
http://localhost:3000
```
